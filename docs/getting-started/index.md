# Get started

Choose a path based on whether you are joining an existing installation or
setting one up.

| Your situation | Next step |
| --- | --- |
| Your organization already runs Hubuum | Ask for the frontend or API URL and an account, then [choose an interface](../integrations/clients.md). |
| You want to evaluate the server locally | [Run your first server](first-server.md), then [make API requests](first-requests.md). |
| You are installing a shared service | Use [single-host deployment](../deployment.md) for the server, frontend, proxy, and supporting services. |
| You need multiple replicas | Follow [distributed deployment](../distributed_deployment.md). |
| You are developing Hubuum itself | Use the [development setup](../development.md). |

Read [core concepts](../concepts.md) to understand collections, classes, and
objects. For the web interface and CLI, installation and interface-specific
instructions live in their [companion repositories](../integrations/clients.md).
